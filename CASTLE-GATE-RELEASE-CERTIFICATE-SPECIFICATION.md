## 2. Canonical Digest Calculation

The `canonical_payload_sha256` is computed by sorting all keys in the certificate object (excluding `attestation`) and generating a single SHA-256 hex digest:

$$\text{Digest} = \operatorname{SHA-256}\left(\operatorname{CanonicalJSON}\left(\text{Certificate} \setminus \{\text{attestation}\}\right)\right)$$

### Verification Rule:
A release certificate is declared **VALID** if and only if:
1. `gate_decision.gate_state === 'PASSED'`
2. `gate_decision.release_authorized === true`
3. `gate_decision.exit_code === 0`
4. `recalculated_digest === attestation.signature_digest`
