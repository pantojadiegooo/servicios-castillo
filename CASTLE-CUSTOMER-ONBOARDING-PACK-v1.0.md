# Castle Security & Quality Gate — Customer Onboarding Pack (v1.0.0)
**Document ID:** `PACK-ONBOARDING-CUSTOMER-v1.0.0`  
**Classification:** Grupo Castillo Client Onboarding & Security Manual  

---

## 1. Información Solicitada al Cliente
1. Razón social y contacto técnico principal (CTO o DevOps Lead).
2. Repositorio acordado para la evaluación y rama base (ej. `main` o `develop`).
3. Canal de comunicación técnica acordado (Slack compartido, Teams o correo electrónico).

---

## 2. Protocolo de Tratamiento de Accesos y Privacidad
* **Lectura Temporal:** El cliente otorga acceso de lectura al repositorio durante el período de evaluación.
* **Cero Telemetría:** El software se ejecuta localmente o en los runners del cliente; **ningún fragmento de código fuente es transferido a servidores externos**.
* **Revocación de Accesos:** A la entrega del *Pilot Closure Report*, el cliente revoca formalmente los accesos temporales concedidos.
