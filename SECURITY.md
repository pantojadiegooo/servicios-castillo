# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

The Grupo Castillo Security Team welcomes responsible security disclosures regarding Castle Gate and its cryptographic verification components.

If you discover a security vulnerability or bypass vector:
1. **Do NOT open a public GitHub issue.**
2. Send encrypted details to `security@grupocastillo.com`.
3. Provide step-by-step reproduction steps or an adversarial test case.

We commit to acknowledging receipt within 24 business hours and providing regular remediation status updates.
