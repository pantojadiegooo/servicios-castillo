## 1. Inventario de Entregables de Castle Emergency

```text
+---------------------------------------------------------------------------------------------------+
| 1. HOTFIX PULL REQUEST / PARCHE DE EMERGENCIA                                                     |
|    - Rama Git con secretos purgados, configuraciones corregidas y código listo para despliegue.   |
+---------------------------------------------------------------------------------------------------+
| 2. INFORME POST-MORTEM DEL INCIDENTE (Incident Post-Mortem Report)                                |
|    - Registro de causa raíz, cronología de eventos, acciones tomadas y tiempo de resolución.      |
+---------------------------------------------------------------------------------------------------+
| 3. RELEASE CERTIFICATE SELLADO (.castle/release-certificate.json)                                 |
|    - Certificado oficial que acredita el desbloqueo del release tras alcanzar Exit Code 0.        |
+---------------------------------------------------------------------------------------------------+
| 4. GUÍA DE PREVENCIÓN Y BLINDAJE (Hardening Advisory)                                             |
|    - Recomendaciones puntuales para que el equipo evite que el incidente vuelva a producirse.     |
+---------------------------------------------------------------------------------------------------+
```
