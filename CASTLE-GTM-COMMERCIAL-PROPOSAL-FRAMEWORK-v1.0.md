---

## 1. Estructura Estándar de una Propuesta Comercial

Toda propuesta emitida por Grupo Castillo debe estructurarse en 6 bloques claros:

```text
1. RESUMEN EJECUTIVO (El problema del cliente y el resultado comprometido).
2. ALCANCE TÉCNICO DETALLADO (Repositorios, controles CQS y nivel Gate).
3. ENTREGABLES FORMALES (Reportes, Dashboards, Pull Requests, Certificados).
4. CRONOGRAMA Y METODOLOGÍA (Duración, sesiones y fases de trabajo).
5. INVERSIÓN Y CONDICIONES (Precios propuestos y garantía de crédito cruzado).
6. LÍMITES Y DISCLAIMERS (Declaración explícita de no-certificación externa).
```

## 2. Plantilla Específica para Propuesta de Piloto C1/C2

```text
================================================================================
                    PROPUESTA DE PILOTO CONTROLADO CASTLE GATE
================================================================================
Cliente:                  [Nombre de la Empresa]
Repositorio Objetivo:     [Nombre del Repositorio]
Nivel de Gate Propuesto:  [Nivel C1 Foundation / Nivel C2 Standard]
Duración Estimada:        1 a 2 semanas calendario (10 días hábiles)

ALCANCE INCLUIDO:
1. Instalación y escaneo baseline con @grupo-castillo/castle-gate v1.0.0.
2. Generación de reporte interactivo (.castle/compliance-report.html).
3. 2 Sesiones de consultoría con Ingeniero Senior de Grupo Castillo.
4. Asistencia técnica para remediación de Gate Breakers (claves expuestas).
5. Emisión y verificación del Release Certificate (.castle/release-certificate.json).
6. Configuración de workflow automatizado en GitHub Actions o GitLab CI.

INVERSIÓN PROPUESTA:      `[PROPUESTA COMERCIAL - SUJETA A RATIFICACIÓN]` $900 USD
CONDICIÓN ESPECIAL:       50% del valor pagado acreditable hacia la licencia anual.
================================================================================
```
