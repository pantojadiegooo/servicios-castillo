## 1. Drivers de Valor y Variables de Precios

La tarificación de los servicios profesionales de Grupo Castillo se basa en el impacto técnico y el nivel de esfuerzo de ingeniería, estructurado a través de 6 variables objetivas:

```text
+---------------------------------------------------------------------------------------------------+
| 1. Complejidad y Tamaño del Código (Número de repositorios, líneas de código y microservicios).   |
| 2. Nivel de Gate Objetivo (Políticas base C1/C2 vs. políticas avanzadas C3→C6).                   |
| 3. Profundidad del Análisis (Diagnóstico estático vs. auditoría arquitectónica profunda).         |
| 4. Nivel de Urgencia y Tiempo de Respuesta (Estándar vs. intervención de emergencia < 2 horas).   |
| 5. Dedicación de Consultoría (Horas de ingeniería y sesiones con arquitectos senior).             |
| 6. Modalidad de Contratación (Proyecto puntual vs. suscripción recurrente mensual).               |
+---------------------------------------------------------------------------------------------------+
```
